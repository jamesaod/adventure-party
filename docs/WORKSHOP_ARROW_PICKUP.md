# Workshop arrow pickup visualization — local R238C308

Equipment fitting now offers **Show arrow pickup point (cyan)** and **Go to pickup**. The cyan sphere/cross marks the arrow's starting nock, not the bow grip or the quiver's mesh pivot. It follows the actual runtime pickup socket through poses and camera rotation. It is visible through the model for fitting, and keeps a fixed physical marker size when the quiver is resized. The existing gold grip marker remains separate.

Manual Quiver uses `createStudioBackEquipment.getArrowSocket()`, so Back position/rotation/scale edits move the marker and runtime arrow origin together. Automatic bow quiver uses the existing shared bow pickup controller calibrated at `bowPickupTime()`. An assigned Bow action provides calibration when another action is being previewed; an active preview with Bow timing takes precedence. Automatic pickup requires a supported bow and animation time before Draw. Manual origin fitting is available without a bow.

`workshop-arrow-preview.mjs` samples calibration on a temporary mixer and restores every displayed track before returning. It preserves the active action, playback clock, hand offsets and fit settings. The existing Workshop animation loop calls `setBowState(bowArrowStateAt(...))` for the full quiver/carry/nock/release preview. No extra animation loop, saved marker data or combat timing changes. Go to pickup pauses at the correct local time even for trimmed/speed-adjusted clips. Explicit saved pickup timing is preserved when opening and editing ranges.

Asset loads are guarded against clearing/changing the model; removing a bow or switching Back items clears borrowed spare arrows and automatic geometry. The shared pickup controller now clears its root reference on disposal. Cache-busted Workshop entry and affected imports use R238C308. Local integration only; user performs visual QA.
