# Shield assets

## Round Wooden Shield — Candidate Rev 71

Adventure Party's current shield is based on the user-supplied
`round+wooden+shield+3d+model.glb`.

### Source upload

- Bytes: **781,832**
- SHA-256: **4a0bad4a77b3e5a086576b00e8890ef5f0c2417ea423559ef7196acd8a488928**
- glTF 2.0 binary generated by Tripo
- 1 scene / 1 node / 1 mesh / 1 material
- 5,648 position vertices
- 8,478 triangles
- no skin and no embedded animation
- three embedded 1024 × 1024 JPEG maps: normal, base color, and roughness/metallic
- source bounds: X **-0.499817..0.499817**, Y **0..1**, Z **-0.124596..0.124596**

### Runtime representation

Candidate Rev 71 uses a self-contained wooden round-shield renderer rather than
shipping a second binary GLB. The runtime shield preserves the uploaded model's
overall round proportions and source identity, then builds the visible wood
face, darker rim/plank seams, and metal boss with Three.js materials.

The original GLB remains the authoritative source for provenance and detailed
geometry. This runtime representation keeps Candidate loading reliable while
the equipment attachment and sizing system is being developed.

### Canonical item record

`js/item-catalog.mjs` owns the canonical Adventure Party item record for the
wooden shield. It ties together:

- AD&D medium-shield rules
- source model provenance and SHA-256
- source model bounds
- render-calibrated size
- appearance / attachment identity

At the current calibrated 100% visual scale, the shield is approximately
**35 inches in diameter** relative to Dungeon Crawler Carl's canonical
**76-inch (6′4″)** height. This is a render calibration, not a claim that the
source model represents a historically exact 35-inch shield.

### Left-arm mount and Studio controls

The approved base mount remains:

- Bone: `mixamorig:LeftHand`
- Base position: **(0, 0, 0.04)**
- Base rotation: **(0°, 0°, 0°)**
- Native model scale: **0.45**

Studio exposes four live controls relative to that base:

- **Shield scale:** 25%–200%
- **Closer / farther from arm:** -3 to +6 inches
- **Up / down forearm:** -8 to +8 inches
- **Rotate around forearm:** -180° to +180°

The forearm slide and roll directions are derived from Carl's actual animated
left forearm. Saved Studio settings are carried into Test in Combat so generated
sprites use the same shield tuning.

## Historical bronze QA proxy

Candidate Revs 67–70 used a procedural bronze round-shield proxy while the
left-arm attachment system was being calibrated. Candidate Rev 71 replaces its
appearance with the wooden texture set and source proportions while retaining
the approved Rev 69 mount and Rev 70 controls.
