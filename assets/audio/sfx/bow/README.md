# Selected bow audio

Five unchanged CC0 WAV excerpts selected by James on 2026-11-12 (UTC). Exact original IDs, hashes, source URLs, authors, extraction ranges, and licenses are retained in selection.json.

Draw/release/flight: Ben Jaszczak & Brian Nelson / Still North Media, recorded. Flesh impact: SFXMint, AI generated. Mud Thud: TinyWorlds, recorded Foley. All CC0-1.0.

Flesh plays only after a hit on the intended target survives Mirror Image. Mud Thud plays once for every miss or scenery contact, including a stray shot; no surface-specific substitution. Other existing world effects (such as breaking glass) still play.

The recordings use the shared SFX volume/mute. Draw keeps its original pitch and ends at the animation's release phase. Release and pass-by start with the arrow; impact starts on arrival.
