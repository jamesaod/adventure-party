Walls, doors & windows

Doors and windows need floor on both sides. Windows transmit sight/light and block movement/projectiles. Erase removes authored edges; paint floor to extend beyond a void boundary.

Quarter-round walls

Each curve occupies one floor square. Place NW / NE above SW / SE in a 2×2 block to make a round tower. Curves replace the two outer straight walls. Doors and windows remain on straight edges.
