Walls, doors & windows

Doors and windows need floor on both sides. Windows transmit sight/light and block movement/projectiles. Erase removes authored edges; paint floor to extend beyond a void boundary.

Quarter-round walls

Select a curved wall square to edit its faces.

Each curve occupies one floor square. Place NW / NE above SW / SE in a 2×2 block to make a round tower. Curves and authored straight walls can coexist, including along the outside square edges. Doors and windows remain on straight edges.

Encounter area settings

Drag a rectangle. Shift adds; Alt subtracts. Click an area with Select to select it all.

Select floor or door squares, then save. Walls are skipped. Areas cannot overlap. Each C number identifies one encounter; victory clears its whole area. Keep the enemy anchor within five squares of every trigger square. Removal supports Undo.
